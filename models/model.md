# layers.py
## EmbeddingLayer
### 功能
生成三种类型的嵌入向量：`c_embeddings`（中心代码嵌入），`n_embeddings`（邻居代码嵌入），以及` u_embeddings`（无关代码嵌入）`

## GraphLayer
### 功能
通过邻接矩阵`adj`对输入的编码及其邻居进行编码，生成中心代码和邻居代码的嵌入表示

该层考虑了代码之间的共现关系，并通过线性变换和激活函数来增强表达能力
### 操作
- 计算中心代码和邻居代码的嵌入
- 通过邻接矩阵计算不同类型的交互嵌入（如中心-中心，中心-邻居）
- 将上述嵌入合并并通过线性变换和激活函数输出最终的中心代码和邻居代码嵌入
## TransitionLayer（修改）
### 功能
- 时间过度层，基于GRU单元处理序列数据
- 结合单头注意力机制捕捉不同类型编码之间的交互
- 动态更新隐藏状态，并根据输入的时间步长选择性地关注重要信息

# model.py
## Classifier
### 功能
- 全连接分类器
- 接收来自前面各层的特征表示，并通过线性变换、激活函数和Dropout层输出最终的预测结果。
## Model
### 功能
- 核心类，它组合了上面定义的所有层，形成了一个完整的EHR预测模型。
- 接收患者的历史诊断代码序列作为输入，并输出预测结果。
